# Number Guessing Game 🎲

A simple, interactive command-line interface (CLI) number guessing game built with Python. 

## 🎮 How to Play

The computer will randomly select a secret number between **1 and 100**. Your goal is to guess this number within **5 attempts**. After each guess, the game will provide feedback indicating whether your guess was too high or too low.

## 🚀 Features

* **Input Validation:** Handles non-integer inputs gracefully without crashing.
* **Range Checking:** Ensures guesses fall within the valid range (1–100).
* **Attempt Tracking:** Keeps count of your attempts and displays remaining tries after each guess.
* **Interactive Feedback:** Real-time hints ("Too low!" or "Too high!").

## 📋 Prerequisites

Make sure you have **Python 3.x** installed on your system. You can check your Python version by running:

```bash
python --version
```

## ⚙️ Running the Game
1. Clone the repository:
```bash
git clone https://github.com/thecss/python-number-guessing-game.git
cd python-number-guessing-game
```

2.  Run the script:
```bash
python game.py
```
